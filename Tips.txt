/////////////////////// POUR CLICKHOUSE //////////////////////

Lorsque changements dans le build.sbt il faut recompiler
sbt compile 

telechargez clickhouse
installez clickhouse normalement ça met un msg install
vous allez créer un compte mais osef
dans un terminal
clickhouse server

dans l'autre terminal, classique sbt run mais la vous choisissez DATABASE (en gros type 1)

Le Pb avec ça c'est que le server dans le main ne se lancera pas donc les routes sont inutilisables
Donc si quelqu'un veut s'y coller : faire en sorte que l'on puisse lancer ces 2 trucs en meme temps
