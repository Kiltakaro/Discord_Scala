# Discord_Scala
Discord en scala

## Prérequis, installations nécessaires

- Clickhouse
- Node
- Sbt

## Lancement

3 tabs / terminaux différents

1. ```cd backend && sbt run```
2. ```cd frontend && npm run dev```
3. ```cd database && clickhouse-server``` ou ```cd database && ./clickhouse-server```
